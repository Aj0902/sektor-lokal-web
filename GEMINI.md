# Sektor Lokal Web Project Rules

Aturan dan panduan utama untuk proyek `sektor-lokal-web`.

## 1. Isolasi Proyek
Proyek ini bertempat di `c:\AI Challlenge\sektor-lokal-web`. Proyek ini terisolasi murni untuk pembuatan Web Platform Next.js + Vercel + GitHub terkeren, terkurasi, dan otentik.

## 2. Aturan Data Google Sheets
DILARANG menyebut, mengambil, atau menghubungkan data dari Google Sheets sebelumnya sebelum pengguna (user) memberikan instruksi / notice secara eksplisit. Focus 100% pada pembuatan arsitektur web & UI/UX terkeren dulu.

## 3. Standar Kualitas UI/UX
- Framework: Next.js (App Router, Server Components).
- Aesthetic: Glassmorphism Dark Mode modern (Plus Jakarta Sans font, Tailwind CSS, Lucide Icons).
- Performance: Skor Google Lighthouse 100/100, Fast Load, Responsive.
